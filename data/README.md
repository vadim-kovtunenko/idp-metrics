# Данные для дашборда

Графики берут данные из JSON-файлов в этой папке. На графиках всегда отображаются **последние 12 значений**: в массиве может быть 12, 13, 14 и больше — просто дополняйте данные новыми месяцами. Порядок в файле: от старого месяца к новому.

| Файл | График | Структура |
|------|--------|-----------|
| `gigasearch.json` | IDP GigaSearch | Объект: ключ = фильтр (`common-wo-sbol`, `common-sbol`, `alpha`, `sigma`, `alpha-sbol`), значение = массив из 12 чисел (calls). |
| `summarization.json` | Summarization | Объект: ключ = фильтр (`alpha`, `sigma`, `common`), значение = массив из 12 чисел (calls). |
| `gigaquery.json` | GigaQuery | Объект: ключ = фильтр (`alpha`, `sigma`, `common`), значение = массив из 12 чисел (calls). |
| `initiatives.json` | Количество заведенных инициатив | Объект с полем `"months"`: массив из 12 строк, каждая строка `[gigasearch, gigaquery, summarization]`. |

Ключи с подчёркиванием (например `_comment`) в JSON игнорируются при загрузке.
